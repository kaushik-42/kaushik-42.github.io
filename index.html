01About

I'm a Machine Learning Engineer on CVS Health's AI Platform team — and someone who's genuinely curious about how systems actually hold up once they leave the notebook.

Day-to-day that means LLM-powered document extraction and OCR pipelines, evaluation frameworks (including the in-house LLM-as-Judge tooling we use for quality monitoring), async inference services on FastAPI + GKE, and the unglamorous-but-load-bearing plumbing of usage tracking and client-level chargebacks across foundational services handling 1M+ events. I also help maintain UQLM — CVS Health's open-source library for LLM hallucination detection — as a core contributor.

Before CVS, I earned my M.S. in Computer Engineering at NYU, where I was also a Graduate Adjunct for the Foundations of Machine Learning course at NYU's Center for Data Science. Outside of work, I write occasionally on Medium, play chess, and tinker with anything at the intersection of ML systems and developer ergonomics.

03Open Source

Contributing to the tools others build with

My day job ships behind closed doors, but I also help build the public version of it.

Core contributor · Python

cvs-health/uqlm

Uncertainty Quantification for Language Models — production hallucination detection library.

★ 1.2k stars 125 forks JMLR · TMLR Python · LLMs

UQLM is CVS Health's open-source Python package for detecting LLM hallucinations via uncertainty quantification. It ships black-box, white-box, LLM-as-judge, ensemble, and long-text scorers, has been peer-reviewed in JMLR and TMLR, and is used in production research and product settings. I contribute across the long-text UQ surface, white-box scorer coverage, and runtime ergonomics.

quickstart.py
from langchain_openai import ChatOpenAI from uqlm import BlackBoxUQ llm = ChatOpenAI(model="gpt-4o-mini") bbuq = BlackBoxUQ( llm=llm, scorers=["semantic_negentropy"], use_best=True, ) results = await bbuq.generate_and_score( prompts=prompts, num_responses=5, ) results.to_df() # ↳ scored responses
